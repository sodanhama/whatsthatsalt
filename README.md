# What's that salt?

## Description
This web app allows users to deduce the anions and cations of an unknown given salt, initially aimed for NCERT chem lab, will also later be made useful for A levels chem lab, etc.

## How this works
To highlight the anions and cations most probable to be found in the salt, initial preliminary tests are performed.

These include:
- Physical examination
- Smell
- Solubility
- Dry heating
- Flame test (rare)
- Dilute and concentrated sulphuric acid tests

Finally, group separation for anions and confirmatory tests for anions, followed by the same for cations are performed.

The preliminary tests do not affect the number of tests to be performed, they are akin to a formality.
